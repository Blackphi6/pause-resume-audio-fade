Pause Resume Audio Fade
日本語 English

一時停止の「ブツッ」を、
なめらかに。

動画や音楽を止めるたびに音量を下げ、再開するたびに上げます。急に切れる音も、急に戻る音も、なくなります。

「再生」を押すと、やわらかい和音が鳴ります

フェード

再生してから「一時停止」を押し、フェードを「なし」に切り替えて、もう一度止めてみてください。止まる瞬間が、赤い棒で見えます。音量を下げてから試してください。

どれを使えばいい？

  • Chrome / Firefox 拡張機能

    ブラウザの動画サイトで効きます。YouTube、Netflix、Prime Video、TVer、ABEMA など。Chrome、Firefox 142 以降

    Chrome に追加 Firefox に追加

  • Mac アプリ

    Mac のどのアプリの音にも効きます。QuickTime、VLC、ブラウザなど。メニューバーに常駐します。Apple シリコンの Mac、macOS 14.2 以降

    ダウンロード

  • Windows アプリ

    PC から鳴る音全体に効きます。タスクトレイに常駐し、.NET などの追加インストールは要りません。出力が 1 つだけの PC では、無料の VB-CABLE が必要です

    ダウンロード

  • Android アプリ準備中

    スマホの音楽・動画アプリの、一時停止と再開に効きます。Google Play での公開に向けて準備しています。

    進み具合を見る

Mac をお使いなら、ブラウザ以外の音にも効くので、拡張機能より Mac アプリがおすすめです。

できることと、限界

フェードの長さは、自分で決められる

拡張機能は 100〜3000 ms の範囲で、フェードアウトとフェードインを別々に。Mac 版と Windows 版は、プリセットとフェードインの長さを選べます。

止まる「前」にさかのぼって、フェードする

Mac 版と Windows 版は、他のアプリの一時停止を横取りできません。そのため、音を 0.1〜0.35 秒遅らせて、止まった瞬間に直前の音へフェードを掛けます。映像との音ズレが気になるときは、短いプリセットを選んでください。

通話と読み上げ音声には、掛けない（Mac 版）

マイクが使われている間は、フェードを止めます。読み上げ音声のように、滑らかに始まって終わる音にも掛けません。文頭や語尾が弱くならないためです。

無料で、広告なし。音声は外に出ません

どの版も、音声を保存も送信もしません。ソースコードは GitHub で公開しています。

困ったとき

Mac で「開けません」と出る

個人開発で、Apple の公証を受けていないための表示です。アプリを右クリックして「開く」を選び、もう一度「開く」を押してください。初回だけです。

Windows で「WindowsによってPCが保護されました」と出る

署名していない exe のための表示です。「詳細情報」を押してから「実行」を押してください。

Windows で VB-CABLE が必要と言われた

元の音を鳴らさずに逃がすための「使っていない出力」が、1 つ必要です。スピーカーとヘッドホンなど、出力が 2 つ以上ある PC では、何も入れずに使えます。出力が 1 つだけの PC では、無料の仮想ケーブル VB-CABLE を入れてください。アプリの案内画面が手順を出します。

フェードが掛からないサイトがある

拡張機能は、対応サイトの一覧にあるサイトでだけ動きます。サイト側が音量の変更を受け付けない場合も、効きません。Mac 版と Windows 版は、サイトを選ばず、全体の音に効きます。
